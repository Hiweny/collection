# 雪线之上 · 本地媒体收藏夹
一个纯静态的个人媒体收藏工具，用来整理公开分享的图片 / 视频链接。
## 当前功能
- 粘贴抖音、小红书等公开分享链接并尝试解析
- 直接收藏图片 URL
- 图片与视频预览
- 搜索与类型筛选
- 浏览器本地保存收藏数据
- JSON 导入 / 导出
- 自定义页面背景：
  - 填入任意图片直链作为固定背景（内置一张默认背景图）
  - 或选择「随机收藏图片」，每次刷新页面从已收藏的图片直链中随机抽一张作为背景
  - 背景设置保存在浏览器本地，下次打开自动沿用
- 图床工具（360 图床）：
  - 外链转存：粘贴图片外链，转存为 360 图床直链
  - 本地上传：点击选择或直接拖拽本地图片，以 base64 POST 上传并返回直链，支持 JPG / PNG / GIF
  - 直连失败时自动经 CORS 代理重试，结果可一键复制或直接收藏
- 单文件前端页面，核心逻辑集中在 `index.html`
## 当前结构
```text
collection/
├── index.html
├── data/
│   └── collection.json
└── README.md
```
早期版本中的独立 `style.css`、`app.js` 等文件已经合并/移除，当前仓库以 `index.html` 为主要页面文件。
## 数据与隐私
收藏数据与背景设置均保存在浏览器本地（localStorage）。项目不提供自己的云端数据库。
链接解析、图床上传依赖第三方公开接口，因此接口是否稳定、是否允许跨域请求取决于第三方服务当前状态；跨域受限时页面会自动尝试公共 CORS 代理。
## 边界
仅用于收藏公开、本人拥有或已获授权的内容，不绕过登录、付费、DRM 或私密权限。
