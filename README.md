# 雪线之上 · 本地媒体收藏夹

一个纯静态的个人媒体收藏工具，用来整理公开分享的图片 / 视频链接。
线上地址：<https://hiweny.github.io/collection/>

## 当前功能

- 粘贴抖音、小红书等公开分享链接自动解析，图片会自动转存到图床，防止防盗链失效
- 直接收藏图片 URL / 多行图片直链（首行可作为标题，整体作为一个图集）
- 图片与视频预览、图集内多图切换
- 搜索与类型筛选
- 浏览器本地保存收藏数据，支持无上限收藏
- 导入 / 导出图集（纯文本，`# 标题 | 平台` + 每行一个直链），导出后再导入顺序与导出前完全一致
- 随机图片展示卡：定时淡入淡出轮播随机收藏图片（可在设置中开关），右下角可一键复制当前图片直链；手动点击切换会重置轮播计时
- 一言：山河 / 诗经两套接口奇偶轮换，淡入淡出切换
- 随机背景音乐（网易云 / 酷我），播放时封面缓慢旋转
- 自定义页面背景：
  - 填入任意图片直链作为固定背景（内置一张默认背景图）
  - 或选择「随机收藏图片」，每次刷新从已收藏图片中随机抽一张
  - 可调节背景模糊度与亮度；设置保存在浏览器本地
- 图床工具（外链转存 / 本地上传）：
  - 外链转存：粘贴图片外链，转存为 360 图床直链
  - 本地上传：点击选择或拖拽本地图片 / 文件（可多个），由 [pone.rs](https://pone.rs/) 免费文件托管，返回直链
  - 结果可一键复制，图片可预览并直接收藏
- 单文件前端页面，核心逻辑集中在 `index.html`

## 安卓 APK

同仓库提供安卓客户端「雪线之上」，以全屏沉浸式 WebView 承载线上网页，并通过原生桥接零侵入解决浏览器端的跨域问题：

- 抖音 / 小红书解析在本地完成：原生调用解析接口 → 全部图片走 360 外链转存 → 回填网页直接收藏，无需手动选择图片
- pone.rs 上传、360 转存、解析接口的请求由原生 OkHttp 直连，不依赖公共 CORS 代理，且异步执行不阻塞页面
- 导入 / 导出通过系统文件框架（SAF）完成，与网页版数据完全互通
- 由 GitHub Actions 构建并发布，下载最新 Release 中的 APK 即可安装

## 数据与隐私

收藏数据与背景设置均保存在浏览器本地（localStorage），项目不提供自己的云端数据库。
链接解析、图床上传依赖第三方公开接口（360 图床、pone.rs、bugpk 解析等），其可用性取决于第三方服务当前状态。

## 边界

仅用于收藏公开、本人拥有或已获授权的内容，不绕过登录、付费、DRM 或私密权限。
