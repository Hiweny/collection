# 雪线之上 · 本地媒体收藏夹

一个纯静态的个人媒体收藏工具，用来整理公开分享的图片 / 视频链接。

## 当前功能

- 粘贴抖音、小红书等公开分享链接并尝试解析
- 直接收藏图片 URL
- 图片与视频预览
- 搜索与类型筛选
- 浏览器本地保存收藏数据
- JSON 导入 / 导出
- 单文件前端页面，核心逻辑集中在 `index.html`

## 当前结构

```text
collection/
├── index.html
├── data/
│   └── collection.json
└── README.md
```

早期版本中的独立 `style.css`、`app.js` 等文件已经合并/移除，当前仓库以 `index.html` 为主要页面文件。

## 数据与隐私

收藏数据主要保存在浏览器本地。项目不提供自己的云端数据库。

链接解析依赖第三方公开接口，因此接口是否稳定、是否允许跨域请求取决于第三方服务当前状态。

## 边界

仅用于收藏公开、本人拥有或已获授权的内容，不绕过登录、付费、DRM 或私密权限。
